#threads

How threads work

Write a #tag anywhere in an entry and that writing joins a thread. Open the thread and you get everything you have ever written under it, in order, on one page.

There are no threads to set up in advance. You make one by typing it.

Tag a single paragraph

A tag anywhere inside an ordinary paragraph tags that paragraph and nothing else.

Slept badly, then swam anyway. #swim 1.5km and it felt like three.

Start a section

A line that begins with a tag opens a section. Everything below it belongs to that thread — including blank lines and the paragraphs that follow — until the next line that starts with a tag.

#swim 2km before eight. The pool was empty the whole way, which never happens on a Thursday. #food Lemon pasta again.

End a section

A line of three or more dashes closes the current section, so what follows is untagged again.

#swim Easy 1km. --- Back to no thread in particular.

Nest related threads

Use a slash to nest. #swim/race is its own thread and also rolls up into #swim, so you can keep the detail without losing the overview.

#writing

Writing

Ariadne opens on today. The date is the entry's title until you give it one of your own, and there is nothing to choose before you can start typing — no blocks, no fields, no templates.

Click the date to jump to another day. Each day can also carry a weather and a mood mark, both optional.

You can change how tagged text looks while you write, in Settings: Wash tints the passage, Rule marks it with a hairline in the margin, and Minimal shows a quiet label instead.

#reading

Rereading

  • Threads — pick any thread in the sidebar to read it start to finish.
  • Overview — a year of writing as a heatmap coloured by thread, plus a month calendar and a per-thread timeline. Filter to one thread, or several.
  • Read — one day per page with everything else out of the way. Arrow keys turn the page; Escape leaves.
  • Search — every word you have written, including inside tags.

#backup

Where your journal lives, and how to back it up

Ariadne keeps everything on your Mac, in the app's own private storage. Nothing is sent anywhere — see the privacy policy.

The consequence is worth being clear about: deleting the app deletes the journal on that Mac. Unless iCloud sync is on, there is no other copy to restore from.

So export regularly. Settings → Export saves your whole journal — every entry, every thread and its colour — as a single file you choose the location for. Keep it somewhere you already back up.

Importing never destroys anything. A day the file does not mention is left alone, and an incoming entry only replaces a local one if it is genuinely newer — so restoring an old backup over newer writing cannot cost you the newer writing.
#moving

Moving to a new Mac

  • On the old Mac, choose Settings → Export and save the file.
  • Copy it across however you like.
  • On the new Mac, install Ariadne and choose Settings → Import.

Your entries, threads and thread colours all come across.

#trouble

If something goes wrong

My entries are gone

Check that you are signed in to the same macOS user account — Ariadne's storage belongs to your user account, so another account on the same Mac has its own empty journal. If you have an export, Settings → Import will restore it without harming anything already there.

Import says the file isn't a Ariadne journal

Ariadne imports the file its own Export produces. If the file has been edited by hand and is no longer valid, the app will refuse it rather than import something broken.

A tag isn't creating a thread

Tags must start with a letter or a number — #swim and #2026 work, #_swim does not. Tags are also case-insensitive, so #Swim and #swim are the same thread.

The app looks wrong after an update

Quit and reopen it. If that doesn't help, get in touch and describe what you see — and export first if you can.

#contact

Getting in touch

Email cq.feedback@gmail.com. It helps to include your macOS version, the version of Ariadne from the About panel, and what you expected to happen.

Since 0.2, Ariadne can sync between your Macs through your own iCloud. It's off until you turn it on in Settings; on, your entries travel encrypted between your devices and never through a server of ours. If two Macs edited the same day while apart, Ariadne keeps both versions in that day, separated by a divider that says where each came from — sync never discards writing.
