# ariadne-site

The public support and privacy pages for **Ariadne**, a plain-text journal you
can reread by thread.

Served by GitHub Pages:

- Support — https://carol-lab.github.io/ariadne-site/support.html
- Privacy — https://carol-lab.github.io/ariadne-site/privacy.html

Three self-contained HTML files, no build step and no dependencies. The app's
source lives in a separate private repository.

Source of truth for these pages is `store/deploy/` in the app repo; edit them
there and copy across, so the two copies do not drift.
